# Wazuh SIEM Home Lab

This project demonstrates the deployment of a Security Information and Event Management (SIEM) system using Wazuh in a VirtualBox environment.

## Lab Environment

- Ubuntu 22.04.5 (Wazuh Manager & Dashboard)
- Windows 10 (Wazuh Agent)
- VirtualBox Internal Network

## Objectives

- Deploy and configure a SIEM solution (Wazuh)
- Collect and analyze logs from multiple endpoints
- Detect suspicious activities such as brute-force attempts and network scans
- Simulate real-world attack scenarios in a controlled lab environment

## Skills Demonstrated

- SIEM deployment and configuration
- Endpoint log monitoring (Windows & Linux)
- Security event analysis
- Basic incident detection and investigation
- Virtualized lab environment setup

## Repository Structure

- `configs/`– Configuration files and settings
- `notes/` – Installation steps and command notes
- `reports/` – Incident analysis and findings
- `screenshots/` – Dashboard and alert evidence

## Tools Used

- Wazuh
- Ubutu
- Debian
- VirtualBox
- Kali Linux
- Windows 10
- Metasploitable2
